# 0005 — 公开仓库与内部标识分离

- 状态:已接受(2026-09-10)

## 背景

项目开源需要自解释的名字(campus-apply-tracker / 「校招投递控制台」),但运行时标识(LaunchAgent `com.ats-status.*`、数据目录 `~/.ats-status`、CLI 命令 `ats`)已被用户机器安装引用,改动即破坏升级路径。

## 决策

**只改公开呈现层**(仓库名、README 展示名、package.json 的 name),**内部标识一律不动**;README 注明数据目录位置。公开仓库以单一初始提交起步(v1.0.0),私有开发历史以 git bundle 留存本地。

## 后果

- 已安装的服务、定时任务、数据目录升级无缝;
- 名字两套(repo 名与内部目录名不同)需要一条 README 说明,避免困惑;
- 未来若确需统一标识,须写迁移脚本(LaunchAgent 重装 + 数据目录搬迁),成本已知且暂不支付。
