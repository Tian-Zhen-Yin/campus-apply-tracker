# 0004 — 开源:全预置保留 + 使用红线

- 状态:已接受(2026-09-10)

## 背景

六家站点(字节/阿里/美团/携程/小红书/快手)的预置状态接口与保活策略是项目易用性的核心。公开分发后,站点方可能针对性升级风控(阿里校招门户已迁移过一次),工具越流行、接口失效越快,最终伤害所有用户。

可选:全保留预置 / 高风险站点不预置 / 纯框架无预置。

## 决策

**全部保留预置**,同时 README 首屏写明使用红线:个人自用、默认 12 小时低频查询(±40% 抖动、夜间静默)、禁止批量采集与二次分发。

理由:预置信息用抓包向导本来就能获得,遮掩不提供实质保护,只增加普通用户的摩擦;诚实的红线文档才是对站点方和用户双方的交代。

## 后果

- 预置接口失效时(站点改版/风控升级)由 capture 向导兜底,用户可自行重新识别;
- 若某站点明确表示反对,按站点下架其预置,不影响其余站点。
