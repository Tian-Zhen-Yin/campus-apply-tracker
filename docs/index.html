它能替你做六件事

每一件都围绕同一个原则：该自动的自动，该你拍板的绝不替你决定。

◎

官网状态自动聚合

人工扫码登录一次，之后每天三个时点（工作日 9:30 / 14:30 / 20:00）低频查询官网投递进展，状态一变弹系统通知。深夜从不查询，接口失败自动降级，任何有「我的投递」页的公司都能用抓包向导自行接入。

✉

邀约邮件不漏看

IMAP 官方授权拉取邮箱（支持多邮箱），自动识别笔试 / 面试 / Offer / 感谢信，并把「几面、几点、哪个会议软件」从正文里提取出来挂到对应岗位下，配套飞书群推送。

⌕

岗位线：收录到跟进

「岗位收录助手」插件在岗位详情页一键识别公司/岗位/城市，收录同时默认记为已投递（可开悬浮球，右下角自动浮现）；岗位库开箱即用原厂岗位包，你自己的腾讯文档表可多源添加；截止七天红标、内推码一键复制、官网在途投递提示「可能已投」。

⇄

旧台账无缝迁移

一直在用「校招投递管理」台账？「数据安全 → 迁移到校招投递控制台」一键搬家：投递记录幂等合并、岗位库与「不投」标记原样带过来，重复执行不产生脏数据；台账本身继续可用。

✎

人工修正与拍板

官网进展与你的记录有出入时，进入「拍板」流程由你逐条确认，绝不静默改数据；人工修正优先于官网抓取，归档的记录随时可恢复。

🔒

隐私是设计不是口号

登录会话、投递记录、邮箱授权码全部只存你电脑的 ~/.ats-status 一个目录，没有服务器、不上报任何东西；插件识别在本页完成、结果只发本机控制台；卸载 = 删目录。

🍎 macOS 完整版

下载解压 → 双击「安装.command」。首次被 Gatekeeper 拦截属统一安全检查：系统设置 → 隐私与安全性 → 「仍要打开」。需要 Node.js ≥ 18 与 Chrome。

不想处理弹窗？终端粘贴：

curl -fsSL https://gitee.com/YinTianZheng/campus-apply-tracker/raw/master/scripts/quick-install.sh | bash

或 Homebrew：brew install --cask Tian-Zhen-Yin/tap/campus-apply-tracker

🧩 岗位收录助手（浏览器插件，可选）

装到 Chrome / Edge 后，在任意岗位详情页点插件图标 → 自动识别公司/岗位/城市（可改）→ 一键收录，默认同时记为已投递（直接进投递总览；只是先收藏还没投，取消勾选即可）。可开启页面悬浮球：岗位页右下角自动浮现小球，点开即收录（二次授权，仅本机判断，不外发数据）。识别在本页完成，结果只发到你电脑上的控制台，不经任何服务器。

安装：解压 → chrome://extensions 打开「开发者模式」→「加载已解压的扩展程序」选择文件夹（详见包内安装说明）。

上手只要三步

装好后打开 http://127.0.0.1:7788，跟着页内的「上手清单」走即可。

1

接入一家公司

扫码登录你投过的招聘官网（推荐从快手开始，有预置接口免抓包）。会话保存在本机，之后自动复用。

2

查一次状态

点「立即查询」，该公司的投递进展立刻出现在投递总览；之后定时任务每天自动跟进，变化弹通知。

3

（可选）配邮箱 + 装收录插件

IMAP 授权码接入邮箱，邀约自动提醒；装「岗位收录助手」，在岗位页一键收录并记为已投递——旧台账用户再点一下「迁移」，历史数据全过来。

⚠️ 使用红线（请务必读完再装）：个人自用——默认低频查询（12 小时 ±40% 抖动、夜间静默）是有意设计，请勿改小间隔、勿批量采集、勿二次分发或商业化；招聘站点随时可能改版，工具不承诺持续可用；本项目与上述公司无任何关联，请遵守各站点服务条款，账号风险自负。
