设置与帮手

邮箱、推送、定时任务——配好一次，之后不用管
邮箱监控

开启方法：邮箱网页版设置里开启 IMAP 服务并生成授权码（163：设置→POP3/SMTP/IMAP；QQ：设置→账户）。可添加多个邮箱，每轮查询会全部拉取；笔试/面试邮件推送到飞书，邮件只存本机。

飞书推送

有状态变化时往群里推卡片。建机器人：飞书群 → 设置 → 群机器人 → 自定义机器人。webhook 别外发。

定时任务
服务常驻：检测中… 查询+邮件定时：检测中… 岗位包定时发布：检测中…

查询+邮件定时随控制台自动安装（工作日 9:30 / 14:30 / 20:00）。「岗位包定时发布」为维护者可选：每日 12:00 / 21:30 自动同步文档→打包→提交并推送仓库，用户点同步即拿最新；岗位数异常时自动拦截并弹通知。装好后本页不用开着。

从台账迁移

把「校招投递管理」台账的数据迁进来：投递记录 → 手工登记（总览可见）；岗位库与「不投」标记 → 专用「台账岗位库」岗位源。幂等，可重复执行。

数据位置

每次查状态成功后，自动把官方状态汇总为状态包 out/tracker-sync.json，供「校招投递管理」的状态同步面板读取。
